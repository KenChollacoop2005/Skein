Slime mold versus the route planners

Slime mold is very good at building efficient networks. In a famous experiment it grew a network much like the Tokyo rail system between oat flakes placed like cities. Ordering stops on a shopping trip is a different problem, so I expect it to lose to the exact solver. This page shows by how much.

How each method works
  • Exact optimal: Held and Karp dynamic programming tries every order in a smart way. Used up to 16 stops. Above that it switches to 2-opt and Or-opt and reports how close it is.
  • Nearest neighbor: always walk to the closest item you haven't picked up yet. This is how most people shop.
  • Aisle order: walk the store front to back, aisle by aisle.
  • Slime mold network: the Tero, Kobayashi and Nakagaki (2007) tube model. Each item is a food source. Flow is pushed between random pairs, tubes that carry flow grow, and the rest shrink. The tubes that survive join the items, and the route walks that network depth first from the entrance.
  • Slime mold agents: the Jones (2010) agent model, shown in the animation.
